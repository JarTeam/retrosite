This is where you'll find all my public projects. For the shenanigans that I get up to, check My Shenanigans.

WebTV Redialed

This is likely what you know me from. I was the founder of WebTV Redialed, a revival project for Microsoft WebTV. I have since moved onto greener pastures, but a new team is keeping it alive if this sounds appealing to you.

Gdsk!

This is my "big" project at the moment. Gdsk! is a revival for Google Desktop, featuring support for weather, news, gadget downloads, and a great collection of new and old gadgets up for grabs.

3DS/Wii U Image Share

This is a recreation of Nintendo's "Image Share" service for the 3DS and Wii U. At the moment, it supports posting images with hashtags to Twitter and Tumblr.

PyZuneMetadataServer

This is a recreation of Microsoft's old CD metadata services. It supports Windows Media Player 7 through 12 (on Windows 7 and below), as well as the Zune software.

JarHead's Music Warehouse

This is where I dump all my tracker-based music. All the tunes that you hear (or don't hear if you aren't on IE) on the homepage can be found here.

The Tool That Converts A Select Number Of Currencies To Chicken Shoots

This is an incredibly useful tool that converts all sorts of world currencies to Chicken Shoots, an improved currency whose value is tied to the average going price of Chicken Shoot for Wii in each region.
